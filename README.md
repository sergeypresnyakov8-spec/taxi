# Такси заранее: PWA + Google Таблица

Предзаказ такси: пассажир называет адреса, время и цену, свободный водитель берёт заказ.
Фронтенд раздаёт GitHub Pages, бэкенд это Google Apps Script, база это Google Таблица.

```
PWA (GitHub Pages) → fetch → Apps Script (/exec) → Google Таблица
```

## Запуск за 3 шага

### 1. Обновить бэкенд
1. Откройте таблицу → **Расширения → Apps Script**.
2. Удалите старый код, вставьте целиком `apps-script/Code.gs`, сохраните.
3. Выберите функцию **setup** и нажмите **Выполнить**. Разрешите доступ. Скрипт создаст листы `users`, `drivers`, `orders`, `ratings`.
4. **Начать развёртывание → Управление развёртываниями → ✏ → Версия: Новая версия → Развернуть.**
   Новый URL не нужен, прежний `/exec` продолжит работать.
   Доступ должен быть: выполнять **от моего имени**, доступ **«Все»**.

Если скрипт создан отдельно, а не из таблицы: **⚙ Настройки проекта → Свойства скрипта** → ключ `SHEET_ID`, значение ID таблицы.

### 2. Выложить фронтенд
1. Создайте репозиторий на GitHub и загрузите в корень все файлы **кроме папки `apps-script`** (её можно и оставить, ничего не сломается).
2. **Settings → Pages → Deploy from a branch → main / (root).**
3. Через 1–2 минуты приложение будет на `https://ЛОГИН.github.io/РЕПОЗИТОРИЙ/`.

### 3. Установить на телефон
Android (Chrome): меню → **Установить приложение**. iPhone (Safari): **Поделиться → На экран «Домой»**.

## Настройки
| Что | Где |
|---|---|
| Адрес API, название, города, период опроса | `config.js` |
| Дней пробного периода, цена подписки, город по умолчанию | начало `apps-script/Code.gs` |

После правки `Code.gs` всегда делайте **новую версию** развёртывания. После правки файлов приложения увеличьте `CACHE` в `sw.js` (`taxi-v2`…), иначе пользователи увидят старую версию.

## Как это работает
- **Роли.** Один номер телефона, роль переключается в профиле.
- **Статусы заказа:** `searching` (ищем) → `offered` (водитель сменил цену или время, ждём пассажира) → `confirmed` → `done`, либо `cancelled`.
- **Гонки.** «Взять» защищено блокировкой: два водителя не возьмут один заказ, второй получит «заказ уже взял другой водитель».
- **Контакты.** Телефон водителя виден пассажиру, а пассажира водителю только после подтверждения заказа. В ленте контактов нет.
- **Обновление данных** каждые 8 секунд, пока приложение открыто. Уведомления приходят, пока приложение запущено (в свёрнутом виде), настоящего фонового push нет.
- **Лист в таблице** можно править руками: заголовки менять нельзя, иначе бэкенд ответит `schema_mismatch`.

## Что упрощено в первой версии
- Вход по номеру **без SMS-кода**: любой, кто знает номер, может войти под ним. Для тестов и узкого круга это допустимо, для публичного запуска нужен код или Telegram-вход.
- **Оплаты подписки нет**: после пробного периода доступ выдаётся вручную, в листе `drivers` в колонке `paid_until` ставится дата в формате `2026-12-31T00:00:00Z`.
- Адрес `/exec` публичный и лежит в `config.js`. Это нормально для Apps Script, но данные защищены только знанием номеров телефонов.

## Переход на настоящую БД
Весь обмен идёт через 17 действий в `ACTIONS` (`Code.gs`) и функцию `api()` во фронтенде. Чтобы перенести базу, замените `Code.gs` сервером с теми же действиями и ответами `{ok, data}`; фронтенд менять не придётся. Слой работы с таблицей изолирован в конце `Code.gs` (`rows_`, `find_`, `save_`).
